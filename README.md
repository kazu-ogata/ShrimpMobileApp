## 📖 Abstract & Project Scope
This project addresses challenges in shrimp aquaculture through a hardware-software integration. The mobile application in this repository acts as the **Data Visualization and Management Interface** for the physical ShrimpSense machine. 

### **Primary Functions of the Mobile App:**
* **Data Monitoring:** Display real-time shrimp counts, biomass calculations, and optimized feeding recommendations generated by the machine's AI processing.
* **Session Authorization:** Securely link the user's mobile account to the physical hardware using a QR-based authorization system.
* **Historical Records:** Store and manage a comprehensive history of machine-generated results for long-term farm monitoring.



---

## 🏗 System Components

### 1. [MobileAppFrontend](./MobileAppFrontend)
A **React Native (Expo)** application designed for portability and ease of use in the field. 
* **Key Tech:** Expo Router, Context API, Axios, react-native-chart-kit.

### 2. [MobileAppBackend](./MobileAppBackend)
A dual-layer service architecture:
* **API Server:** A **Node.js/Express** server managing user authentication (JWT), MongoDB data persistence, and email notification services.
* **Inference Engine:** A **FastAPI** Python server running a custom-trained **YOLO11** model for shrimp detection and biomass logic.
